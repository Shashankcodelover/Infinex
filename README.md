# 🚀 Infinex: Basic AI Learning UI Concept

This project provides a mock UI and basic backend for an AI learning platform concept.

## Features

- **Collegiate Topology API**: A basic in-memory CRUD service (`infinexTopologyService.js`) to manage arrays of "squads" and "corridors".
- **Mock Dashboards**: HTML/CSS/JS frontend showcasing various conceptual views (e.g., AI Mock Interviews, 3D Campus concepts). 
- **Automated Tests**: Basic Node.js tests verifying the in-memory array manipulations.

## 🚀 Quickstart

```bash
cd sup-backend
npm install

# Run automated tests
node --test tests/enterpriseMesh.test.js

# Launch server
node server.js
# Access dashboard at http://localhost:5000/dashboard/dashboard.html
```
